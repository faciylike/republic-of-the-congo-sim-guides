## 三、 躲不开的“实名关”
　　2025年了，在刚果买手机卡，**100%需要实名登记（Règlement d'identification des abonnés）**。这不是建议，是硬性规定！忘带护照复印件？抱歉，柜台大姐会微笑着摇头。流程通常是：
1.  出示护照原件 + 签证页复印件（有时入境章那页也要）。
2.  填写登记表格（法文居多，提前备好姓名、酒店地址等信息）。
3.  柜台拍照存档。
**重要提醒：** 别嫌麻烦！想象一下，急着用网却卡在登记环节的焦躁...提前把护照复印件准备好，能省下至少20分钟。我见过不止一个游客在现场狼狈地找打印店。

## 四、 插卡≠有网！频段与APN设置
　　手机没信号？先别怪运营商，可能是设置没调对！
*   **关键频段：** 刚果主要用 **3G (UMTS 900/2100 MHz)** 和 **4G LTE (Bands 3, 20, 28 常见)**。出发前，最好查查自己手机是否支持这些频段（特别是老旧或某些美洲版手机）。不支持Band 28？在部分偏远地区可能真的会“失联”。
*   **APN是灵魂：** 新卡插入，90%的情况需要手动设置APN（接入点名称）。营业厅一般会给张小纸条，**务必保存好！** 常见APN如 `mtninternet` (MTN), `airtelgprs.com` (Airtel)。建议设置好能上网后，立刻截图保存APN信息——这玩意丢了，重置起来可比找Wi-Fi密码痛苦多了。把它当成你的“通信护照号码”记牢。
